# Deville Advanced Systems — Public Landing Page

This is a standalone static landing page for DAS.

## Files

- `index.html` — page structure/content
- `style.css` — all styling and responsive layout
- `script.js` — mobile menu, animations, active navigation, loader and year
- `assets/` — DAS images supplied for the landing page

## Important

This landing page is static HTML/CSS/JS. It can be deployed on Netlify, GitHub Pages, Cloudflare Pages, Vercel, etc.

Your existing PHP/MySQL application can remain on localhost while it is under development. Do not upload database passwords, `.env` files, or private PHP configuration files to a public static repository.

## Before launch

1. Replace or confirm the WhatsApp number, phone number and email in `index.html`.
2. If you own `devilleadvancedsystems.com`, connect that domain to your static hosting provider after deployment.
3. Add a `favicon.ico` or PNG later if desired.
4. When the PHP/MySQL application is ready, deploy that application to PHP-capable hosting separately or migrate the public site into the same hosting architecture.
